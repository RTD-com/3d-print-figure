## 2. 全局锁定段（8 条 prompt 共用）

```
【角色锁定】<身份>，单体，无底座，无场景。<头身比>；<脸型/眼睛/鼻子/嘴/腮红/眉毛的量化描述>；<肤色与质感>。
【服装锁定】<逐件：材质、颜色、左右位置、数量、可数细节>。
【画布锁定】单一视角、单一主体、1:1 方形、真透明 alpha（无白底/灰底/棋盘格/地面/投影/文字/边框）；**八图统一正交投影、统一尺度/坐标/光照（不用 85mm 长焦与透视混搭）**；主体占画面 78–82%；顶/底不要求脚底边距；左前上方 45° 柔光主光 + 右侧补光，5500K；玩具级微距产品摄影，材质清晰、边缘锐利。
```

## 2.5 3D 手办体积感（Q21，强制；已按 Codex 复核修订）

**全局体积段（可直接复制进每条 prompt）**：

> 将 2D 参考解释为同一件实体 3D 手办：头颅、鼓腮、躯干和四肢形成连续圆润体块，保留原角色姿态与非对称细节。D 为自身前后深度、W 为左右宽度；头 D/W 初始目标 0.85–1.0、躯干 0.60–0.75，正侧参考确认后锁定，不套用于全部部件。四肢圆柱，手脚饱满，鞋和衣缘有厚度。赛璐璐仅指配色，允许体积阴影与 AO。八图统一正交、尺度、坐标和光照，仅移动相机，按真实遮挡显隐；禁止五官蔓延到头顶、后脑或鞋底。

执行规则：
1. **比例按部件自身坐标定义**，只是目标区间，不是一刀切；删除“侧视宽度=正面宽度”这类禁令（头 D/W 可以接近 1.0）。
2. **赛璐璐/纯色块只是上色风格**（纯色+粗描边），允许体积阴影/AO/侧壁受光，不是扁平几何。
3. **8 视角统一正交投影、尺度、坐标、光照**；不要 85mm 长焦与透视混搭；顶/底取消“脚底距底边 6%”要求。
4. **按需求卡和真实遮挡填写可见性**：不要套用其他角色（如 示例角色 配件、鞋尖 15%）的模板；非对称姿态（举手/叉腰）保留，不强求左右对称。
5. **正侧体块先行**：先 `03_front`、`05_left`、`06_right`；用同一正交尺度核对头/躯干深宽比，通过后再出其余 5 张。
6. **3D 生成后必须测量**：从模型 bbox 量头/躯干的 D/W，与图像目标对比；图像阴影不能代替几何测量。
7. 每张 prompt ≥350 中文字符，包含角色/服装/体积/本视角/禁止/画布六块。

## 4. 每条 prompt 的六段式模板

```
用途：product-mockup，混元3D单体多视角参考图。本次仅生成一张单一视角图片，不要拼图。参考图1是身份/服饰/材质参考，只参考角色本身，移除人手/包装/拍摄背景。严格遵循下列锁定要求。
[全局锁定段（角色/服装/画布）]
【体积】[生成交接 prompt 时完整注入本文件 §2.5 的权威体积段，不在其它规范维护全文副本]
【本视角｜<名称>】<相机位置/角度/正交投影>；<该视角可见部件、厚度/侧壁、真实遮挡>；<画面占比/位置>；<该视角特有识别点>；<是否强求对称：默认不强求>。
【禁止】<该视角典型错误 5–8 条：镜像、多余肢体、角度漂移、扁平/纸片感、五官穿透、背景不透明、文字/水印、底座/场景、第二人物…>
【画布】统一正交、同尺度/坐标/光照；主体 78–82%；顶/底无脚底边距。
最终要求：仅移动相机，保持同一母版造型；配件位置/数量/朝向不变；根据指定视角遮挡，绝不镜像翻转；单图、真透明 alpha、方形；必须有 3D 手办体积，不是平面剪影。
```

## 5. 生成策略（S4）

1. **正侧体块先行**：先生成 `03_front`、`05_left`、`06_right`；按 §2.5 用同一正交尺度核对头/躯干深宽比，通过后再生成其余 5 张。
2. **其余视角**：以正面母版为 `Input image 1`（身份参考，不是要翻转的平面图）生成；prompt 写 `Generate a physically correct new orthographic camera view of the same subject`。
3. **单张失败**：用 `precise-object-edit` 定向修（每次只改一个点，列 invariants：identity/camera/accessories/background unchanged），单图最多 3 次。
4. **禁止拼图**；每张一个独立 image_gen 调用。
5. 生成后立即复制到 `3.图片\vN\`，不要只留在 `$CODEX_HOME/generated_images/`；每完成一张更新 `progress.json`。

## 6. 一致性硬规则

- 只移动相机：配件位置/数量/朝向/颜色不随视角改变。
- **每视角在 prompt 内写清左右映射**：front 画面左=角色右；back 画面右=角色右；left45/left 近侧=角色左；right45/right 近侧=角色右；top/bottom 用相机的显式 up 轴映射，见 [40 坐标表](40-blender-mcp.md)；底视不能套用顶视映射。禁止把 front 的换算套到 back。
- 背面/底面必须与正面结构不同（不是正面的镜像）；写清「此视角看不到哪些正面结构」。
- 45° 与 90° 必须区分；写清近侧/远侧遮挡。
- 保留非对称姿态（举手/叉腰），不要为了“正面好看”强行对称。
- 避免出现「云朵/翅膀/尾巴/第二人物/手/包装/文字/边框/投影」等非目标元素。

## 7. 校验清单（S5 用）

- [ ] 8/8 文件存在，命名与顺序正确
- [ ] 每图可解码、固定命名、1:1、同分辨率；默认 `--alpha-mode transparent`：每图有效 alpha 且透明像素占比严格 >0.10（alpha=0）；Q15 白底显式 `--alpha-mode white`：逐图按白底检测，不要求 alpha，报告必须标 mode。统一常量在 `scripts/lib/view_spec.py`。
- [ ] 每张与视角定义一致（角度/投影）
- [ ] 角色身份与母版一致（脸/眼/发型/配色/比例）
- [ ] 左右配件无镜像错误
- [ ] 遮挡关系符合物理
- [ ] **3D 体积感：前后径/侧壁厚度/圆润度达标，无纸片感/扁平剪影**
- [ ] **正侧深宽比：引用 §2.5，从图像/模型测量并记录，不复制另一套区间**
- [ ] **非对称姿态（举手/叉腰）未被强制对称化**
- [ ] 无缺失/多余部件、无第二人物/文字/水印
- [ ] 材质与需求卡一致（至少 4 项可辨）
- [ ] 接触表可读（缩略图网格 + 文件名）

## 8. 接触表

`scripts/build_contact_sheet.py --input 3.图片/v1 --output 3.图片/v1/contact-sheet.png`：3×3 网格、每格下方标文件名、统一缩放；用于 S5 双审与用户确认点②。

校验命令：`python scripts/validate_views.py --input "<projectRoot>/3.图片/v1" --expected 8`；白底分支添加 `--alpha-mode white`。`--views front,left,right,... --expected N` 仅提供未来子集实验接口；现行流程仍为8图。

透明判据：alpha=0的像素占比严格>0.10；white判据：RGB各通道≥250的像素占比>0.10且四角为白，均逐图执行（见统一常量）。
