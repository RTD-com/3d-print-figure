# 3D 打印手办工作流

DSH 管理项目状态和用户确认。Codex 接收指定阶段的交接，完成审核、八视角生成和 Blender 操作。开始前确认输入图片的使用权和第三方处理授权。

## 项目目录

```text
<工作目录>/手办/<项目名-YYYYMMDD>/
├── 1.Codex/       审核、生成记录、运行日志和渲染
├── 2.DSH/         原图副本、需求、提示词、确认与 project.json
├── 3.图片/        八视角版本、校验报告与接触表
├── 4.模型文件/    初版 GLB、按版本保存的 Blend、渲染和修复说明
└── 5.打印/        最终 STL 与打印说明
```

`skillRoot` 指当前技能资源位置，`projectRoot` 指项目目录。原图只读，修复另存新版本，复制或交接时记录 SHA-256。打印目录只放验收用产物。

## 阶段与门禁

| 阶段 | 操作与产物 | 继续条件 |
| --- | --- | --- |
| S0 预检 | 运行 `scripts/preflight.ps1` 和 `scripts/init_project.ps1`，建立目录及 `project.json`。 | 工具和输入就绪 |
| S1 需求 | 从图片提取身份、比例、服装、左右、姿态和打印要求。 | 用户确认需求卡 |
| S2 提示词 | 按[八视角规范](10-eight-view-prompts.md)写全每视角六块内容。 | 统一正交、尺度和光照 |
| S3 提示词审核 | 按[交接契约](20-codex-handoff.md)独立审查八份提示词，修订后记录哈希。 | DSH 与 Codex 均通过 |
| S4 八视角 | 先生成正、左、右并核对体积，再生成余下五张。运行 `scripts/validate_views.py`。 | 八图完整，尺寸与背景达标 |
| S5 图片审核 | 对照需求卡、体积量测和接触表[双审](50-review-rubric.md)。 | 无阻断项，用户确认八图 |
| S6 GLB | 依[混元说明](30-hunyuan-web.md)逐槽上传，回读配置和额度，获得单次授权后生成。 | 已绑定任务且 GLB 有效，或用户提供手动下载的 GLB |
| S7 导入渲染 | 按 [Blender 指引](40-blender-mcp.md)校对真实朝向、毫米尺度、落地和八视角。 | 八图齐全，Blend 可重开 |
| S8 初版修复 | 对照问题清单做第一轮局部修补与基础水密清理，保留初版。 | 用户查看修复对比与限制 |
| S9 造型验收 | 根据反馈迭代，自动修复总计最多三轮。 | 用户明确授权导出，G9 记录绑定最终 Blend |
| S10 STL | 执行[打印检查](60-printing.md)，写检查报告并导出毫米单位 STL。 | 检查全过，用户验收 STL |
| S11 交付 | 汇总版本、验证结果、限制和产物，生成本地交付清单。 | 记录可追溯 |

默认目标为 150 mm 高的树脂手办，最小壁厚 1.0 mm。采用其他规格、分件或抽壳前先确认。角色左右从角色自身视角定义。已知角色 IP 需说明用途，交付中标注个人使用或二创。

## 恢复与排错

- 每阶段更新 `project.json` 的 `status`、`gates`、`artifacts` 和 `resume.nextStage`。恢复时先核对哈希，仅补缺失，重做另存版本。
- 造型验收与打印检查分别记录。自交、薄壁等关键实测缺失时保留 `unknown`，STL 导出门保持关闭。
- 混元网页不可用时，请用户手动生成并提供 GLB，记 `manualFallback=true` 后从 S7 继续。暂停的任务优先恢复原任务状态。
- Codex 超时先检查日志与已有产物。MCP 断线先重连，共享 Blender 会话需用户同意后才重启。其他问题见[排错说明](70-troubleshooting.md)。
- 预计或实际超过 30 分钟的后台任务由 DSH 每 30 分钟汇报已完成数、产物和阻塞项。以用户实际收到的时间为准，恢复或重试沿用计时。完成时发送最终结果。
