# 验证范围

| 能力 | 验证方式 | 状态 |
| --- | --- | --- |
| 两项技能、Schema、语法与安装包资源 | 源码自检和 Windows 安装测试 | 离线覆盖 |
| 八视角文件、相机映射和接触表 | 合成 PNG 和非对称点集 | 离线覆盖 |
| 混元确认、额度判断、逐槽证据与 GLB 格式 | 本地构造输入 | 离线覆盖 |
| Codex 启动、超时、产物和重试 | 本地模拟 CLI | 离线覆盖 |
| G9 确认、哈希证据、失败阻断和交付清单 | 本地合成文件 | 离线覆盖 |
| 当前混元网页、真实账号与额度 | 授权后复核上传槽位、回读、任务绑定和下载 | 待实测 |
| Blender 渲染、MCP、实际模型保形和 STL | 导入真实 GLB，检查方向、尺度、表面与重导入结果 | 待实测 |
| 切片和实物 | 复核壁厚、自交、支撑与尺寸，执行切片和试打印 | 待实测 |

发布验证命令在源码仓库的贡献指南。用户项目的检查记录应标明使用版本和证据，并将未实测项标为 `unknown`。
