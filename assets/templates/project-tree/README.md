# 项目目录模板

`init_project.ps1` 会按以下结构创建项目（严格 1–5，见 Q7）：

```text
<工作目录>\手办\<项目名>-<YYYYMMDD>\
├─ 1.Codex\
│  ├─ 01-提示词审核\
│  ├─ 02-生成记录\
│  ├─ 03-会话日志\
│  ├─ 04-Blender脚本\
│  ├─ 05-回传渲染\
│  ├─ 06-修复\
│  └─ 99-临时\
├─ 2.DSH\
│  ├─ 00-输入\
│  ├─ 01-需求卡\
│  ├─ 02-提示词\
│  ├─ 03-审核报告\
│  ├─ 03-确认\
│  ├─ 04-浏览器记录\
│  ├─ 05-决策记录\
│  ├─ project.json
│  └─ 99-临时\
├─ 3.图片\
│  └─ v1\
├─ 4.模型文件\
│  ├─ 4.1初版\renders\
│  ├─ 4.2表面修复版\renders\
│  └─ 4.9归档\
└─ 5.打印\
```

规则：
- 版本不覆盖，修复一次新建 `4.N`。
- `5.打印` 只放最终 STL 与打印说明。
- 原图只读副本放 `2.DSH\00-输入\`。
- 浏览器 profile 放在项目外的 `.browser-profiles\hunyuan`，不打包不提交。
